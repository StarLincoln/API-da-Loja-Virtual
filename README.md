# API-da-Loja-Virtual
## Pratica integradora com o tema: API da Loja Virtual.

### Depências necessárias para a execuçãoc
- Git
- Node.js
- Typescript
- Express
- CORS
- EJS

### Manual de como usar
1. Acesse o Terminal e digite:
```bash
git clone "https://github.com/StarLincoln/API-da-Loja-Virtual"
```
2. Depois de clonar o repositório acesse a pasta API-da-Loja-Virtual;
```bash
cd "API-da-Loja-Virtual"
```
3. Então, Baixe as depedências:
```bash
npm install
```
4. Após isso, execute o app.ts, digitando:
```bash
npx ts-node "./src/app.ts"
```
5. Abra o seu navegador e acesse esse link:
[http://localhost:3000/index.html](http://localhost:3000/index.html)

6. Quando quiser encerrar, basta acessar o terminal e clicar:
```text
ctrl+C
```
